# 🎵 BeatWave - Web Music Player

BeatWave is a simple and interactive web-based music player built using HTML, CSS, and JavaScript. It allows users to play, pause, and manage songs with an easy-to-use interface.

## 🚀 Features
- Play and Pause functionality
- Song list display
- Interactive UI controls
- Responsive design (works on mobile and desktop)

## 🛠️ Tech Stack
- HTML
- CSS
- JavaScript

## 📌 Project Description
This project demonstrates the use of JavaScript for handling audio elements and DOM manipulation. It is designed to provide a basic understanding of how a music player works in a web environment.
